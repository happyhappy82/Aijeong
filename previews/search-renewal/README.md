# 에이정 AI 검색·웹사이트 리뉴얼 로컬 시안

2026-10-30 기획안을 반영한 정적 홈페이지 시안입니다. 기존 WordPress 운영 사이트와 자동 발행 경로는 변경하지 않았습니다.

실행:

```sh
python3 -m http.server 18266 --bind 127.0.0.1 --directory previews/search-renewal
```

접속: http://127.0.0.1:18266/

- 기존 에이정 네이비 색상, 로고와 Pretendard 폰트를 사용합니다.
- AI 검색 최적화, 웹사이트 리뉴얼, 진행 중인 자체 프로젝트, 진행 과정, 회사 소개, 문의를 구성했습니다.
- 상단 메뉴와 문의 버튼은 같은 페이지의 해당 구역으로 이동합니다. 서비스별 상담 버튼은 문의 유형을 선택합니다.
- 문의 폼은 입력값으로 `mailto:` 이메일 초안을 만듭니다. 전송 완료라고 표시하지 않습니다. 실제 전송은 사용자의 이메일 앱에서 실행합니다. 서버 저장과 실전송 API는 없습니다.
- AI 검색·웹사이트 화면은 ‘서비스 흐름 예시’로 표시했고, 프로젝트는 이번 에이정 리뉴얼 시안입니다. 확인되지 않은 고객명, 실적 수치, 후기는 넣지 않았습니다.
- 기존 AI 교육 링크는 현재 공개 교육 페이지를 새 탭에서 엽니다.
- 추적 코드나 외부 폼 전송은 포함하지 않았습니다. 로컬 시안은 `noindex, nofollow`입니다.
- 운영 반영 시 WordPress 테마의 섹션·메뉴·메타데이터로 옮기고 정식 문의 경로를 연결해야 합니다. 이 시안은 WordPress 통합·운영 배포 완료본이 아닙니다.

정본 기획안: 작업공간 루트 `AIJEONG_HOMEPAGE_REPOSITIONING_PLAN_20261030.md`.
